## Multi-Environment Serving Matrix

`dgem` acts as a unified client and benchmark driver across three primary serving environments:

| Environment | Engine & Backend | Model & Precision | Typical Latency | Primary Use Case |
| :--- | :--- | :--- | :--- | :--- |
| **Apple Silicon (M-series)** | Native Rust Metal (`diffgemma`) | `diffgemma-26b-a4b-it-q4`<br />4-bit quantized (~18.8 GB) | ~1,800 ms (1 read)<br />~4,100 ms (multi-sample) | Local development, edge gating, $0 cloud cost |
| **Google Compute Engine (GCE L4)** | vLLM + Triton Attention (`TRITON_ATTN`) | `nvidia/diffusiongemma-26B-A4B-it-NVFP4`<br />4-bit NVFP4 (18.1 GB VRAM) | **~1,100 ms avg**<br />(pure compute: ~750 ms) | High-throughput batch triage, CI/CD evals |
| **Google Compute Engine (GCE 2× A100)** | vLLM Tensor Parallel (`TP=2`) | `google/diffusiongemma-26B-A4B-it`<br />**16-bit Unquantized** (`bfloat16`, 50.1 GB) | **~2,700 ms avg** | Reference baseline evaluations, zero quantization loss |
| **Google Cloud Run** | Containerized vLLM on L4 GPU | `nvidia/diffusiongemma-26B-A4B-it-NVFP4`<br />4-bit NVFP4 | ~1,200 ms (warm) | Serverless endpoints with scale-to-zero economics |

## Quickstart Workflows

<Tabs>
  <TabItem label="Local Apple Silicon">
    Run sub-second discrete diffusion decisions locally on macOS using Apple Silicon Metal:

    ```bash
    # 1. Build the dgem CLI and set up the diffgemma engine
    make build
    make setup

    # 2. Download the 4-bit model and launch the local Metal server (port 8080)
    make download
    make serve

    # 3. Execute a single-pass structured triage decision with full telemetry
    ./bin/dgem decide -t templates/support_triage.json.tmpl \
      -v 'ticket=Emergency: database connection timeout on primary cluster nodes' \
      --stats
    ```
  </TabItem>

  <TabItem label="Cloud GPU (GCE vLLM)">
    Provision an automated GCE GPU instance, run evaluations, and tear down immediately:

    ```bash
    # 1. Provision 1x NVIDIA L4 running vLLM with DiffusionGemma NVFP4 (takes ~4 mins)
    PRECISION=4 make gce-deploy

    # 2. Run the decision benchmark suite against the live GCE endpoint
    ./bin/dgem bench \
      -u "http://<EXTERNAL_IP>:8080/v1" \
      -m "nvidia/diffusiongemma-26B-A4B-it-NVFP4" \
      -d benchmarks/eval_dataset.jsonl -M slot

    # 3. Mandatory teardown: eliminate idle cost immediately
    make gce-teardown
    ```
  </TabItem>

  <TabItem label="High-Cardinality & WFST Benchmarks">
    Evaluate complex NLU datasets and finite-state transducer text normalization:

    ```bash
    # 1. High-cardinality intent evaluation with entropy-gated tie-breaking (Banking77)
    ./bin/dgem bench-intents --dataset banking77 --workers 16

    # 2. 150-intent multi-domain + Out-of-Scope (OOS) evaluation (CLINC150)
    ./bin/dgem bench-intents --dataset clinc150 --workers 16

    # 3. Semiotic polysemy & NSW text normalization vs. C++ Ecotone WFSTs
    ./bin/dgem bench-ecotone --ecotone-addr unix:///tmp/ecotone.sock
    ```
  </TabItem>
</Tabs>
