## Why DiffusionGemma?

<CardGrid stagger>
  <Card title="⚡️ Sub-Second Structured Decisions" icon="rocket">
    Evaluate classification, triage, and ranking schemas in a single forward pass (~880 ms) without generating sequential text tokens.
  </Card>
  <Card title="🍏 Native Metal Acceleration" icon="apple">
    Runs on Apple Silicon using a low-dependency pure Rust + Metal kernel engine (`diffgemma`), utilizing unified memory efficiently.
  </Card>
  <Card title="📊 Calibrated Uncertainty" icon="random">
    Provides empirical standard error (`stderr`), entropy in nats, and consensus agreement across multi-seed noise draws.
  </Card>
  <Card title="🛠️ Go CLI & Automation ('dgem')" icon="laptop">
    Feature-complete Go assistant tool (`dgem`) with Go template definition files, Viper configuration, and `--stats` telemetry.
  </Card>
</CardGrid>

## Quickstart

```bash
# 1. Build the dgem CLI
make build

# 2. Start the local Metal server (port 8080)
make serve

# 3. Execute a structured triage decision in ~880 ms
./bin/dgem decide -t templates/support_triage.json.tmpl \
  -v 'ticket=Emergency: database returned 500 across all cluster nodes!' \
  --stats
```
