Three Generations of Classification

Zero-Shot + Calibrated

1. Traditional Predictive ML (BERT / XGBoost)

~10 ms · Calibrated

Outputs clean class probabilities, but requires thousands of labeled examples and a retraining cycle every time you add or change a category.

2. Autoregressive LLMs (Chat / JSON Mode)

~2,500 ms · Uncalibrated

Zero-shot flexible at evaluation time, but generates tokens serially from left to right. Early tokens bias later fields, and raw text hides whether the model was 99% sure or guessing 51/49.

3. Decision Models (dgem + DiffusionGemma)

~450 ms · 1-Pass + Entropy (nats)

Combines zero-shot flexibility with single-pass parallel slot readout. Evaluates all decision fields simultaneously on a fixed canvas and outputs exact probabilities ($p_k$) and Shannon entropy ($H$).
